## How to Open the Design

1. Install [Autodesk Fusion 360](https://www.autodesk.com/products/fusion-360).
2. Clone or download this repo:
   ```bash
   git clone https://github.com/LegendSeyi/Fusion_Design.git
   ```
3. In Fusion 360, go to **File → Open → Open from my computer** and select `wing and blades v3.f3d`.
